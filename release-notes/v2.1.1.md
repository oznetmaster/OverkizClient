# OverkizClient 2.1.1

Historical local candidate; never published separately. Superseded by [2.1.2](v2.1.2.md), which includes this correction.

The cloud HTTP 400 message `Too many requests, try again later` now produces `TooManyRequestsException`, retaining the exact server message even when its error code is `AUTHENTICATION_ERROR`, `QUOTA_EXCEEDED`, or absent. HTTP 429 handling is unchanged. No automatic retry, public API, target framework, or runtime dependency changes are introduced. AssemblyVersion remains 2.1.0 for this compatible patch; package and file versions are 2.1.1.
