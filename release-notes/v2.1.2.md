# OverkizClient 2.1.2

This patch fixes two API error classifications without changing public APIs, target frameworks or runtime dependencies.

## Fixed

- Recognize the local gateway error text `"No registered event listener."`, including its quotation marks and period, as `NoRegisteredEventListenerException`. `FetchEvents(autoRegister: true)` can then clear the stale listener and register a replacement using the existing single-recovery limit. The exact server message is preserved; explicit fetch does not retry, and unrelated errors retain their existing handling.
- Map the cloud HTTP 400 message `Too many requests, try again later` to `TooManyRequestsException`, including responses with `AUTHENTICATION_ERROR`, `QUOTA_EXCEEDED` or no error code. The exact message is preserved. HTTP 429 handling and retry behaviour are unchanged.

## Compatibility

Targets remain .NET Framework 4.7.2 and .NET 10. Package, assembly and file versions are 2.1.2. No public methods or runtime dependencies changed. Applications that explicitly pin the assembly version should rebuild against this release.

The quota correction was previously prepared as an unpublished 2.1.1 candidate; both fixes are released together in 2.1.2.

## Validation

The offline regression suite contains 331 cases on each target framework. Coverage includes exact error messages, explicit-fetch behaviour, successful listener replacement, bounded repeated rejection and rejection of similar but unrelated error text.
