# OverkizClient 2.2.1

Cloud responses with `errorCode: QUOTA_EXCEEDED` now raise `TooManyRequestsException` even when the server changes or omits its message. The exception keeps the server's text when available. Existing handling of HTTP 429 and the legacy quota message is preserved.

This patch preserves the public API, runtime dependencies, and support for .NET 10 and .NET Framework 4.7.2. The release also includes a separate portable symbol package.

Validation passed on the workstation with 408 offline tests per framework and on Crestron processor Mono with all 408 offline tests. The quota regressions used simulated cloud responses. [Validation record](https://github.com/oznetmaster/OverkizClient/blob/v2.2.1/release-validation/v2.2.1.json)

Upstream reference [pyoverkiz #2264](https://github.com/iMicknl/python-overkiz-api/pull/2264).
