# OverkizClient v2.0.0

This major release keeps JSON transport details inside the client and makes model serialization explicit. Existing applications must review the [migration guide](https://github.com/oznetmaster/OverkizClient/blob/v2.0.0/MIGRATION-2.0.md) and recompile. The supported targets remain .NET Framework 4.7.2 and .NET 10.

## Public API changes

- Replace `FetchEventsRaw()` and tuple handling with `FetchEvents()`, which returns typed events.
- Await `OpenLocalPairing()` for completion; it no longer returns a JSON payload.
- Read `Execution.ActionGroup` as typed actions instead of dictionaries.
- Dynamic device values, event values and command parameters use CLR primitives and collections instead of `JsonElement`.
- Model attributes define JSON names, numeric handling and tolerant enums. Convenience properties are excluded from serialization.

## Fixes and dependencies

- Validate CozyTouch JWT HTTP responses, missing tokens and malformed token bodies, including escaped JSON strings and the supported compact text token form.
- Reject incompatible enum token types while retaining unknown-name handling.
- Remove unused log4net, Polly and Polly.Extensions dependencies. Newtonsoft.Json is not a dependency; the client performs no logging itself.
- Use stable System.Text.Json and System.Net.Http.Json 10.0.12. The .NET Framework compatibility references Microsoft.Bcl.AsyncInterfaces and Microsoft.Bcl.Memory also use stable 10.0.12, replacing preview versions.

## Validation and test dependencies

All 272 offline tests and six read-only local API tests passed on both desktop target frameworks. These checks do not establish compatibility with every vendor service. Nexity Cognito authentication remains unimplemented.

Tests use NUnit 4.6.1, NUnit3TestAdapter 6.3.0, Microsoft.NET.Test.Sdk 18.10.1 and NUnit.Analyzers 4.15.0. These are development dependencies, not library package dependencies. See the [test guide](https://github.com/oznetmaster/OverkizClient/blob/v2.0.0/OverKizApi.Tests/README.md) for commands and private live-test configuration.

dotnet add package OverkizClient --version 2.0.0
