# OverkizClient 2.1.3

This patch recognizes Overkiz execution failure code `60001` as `FailureType.Internal`. Previously the numeric code was retained without a named enum member. Raw event failure text is preserved.

The new member has an explicit numeric value. Existing enum values, public method signatures, target frameworks and runtime dependencies remain unchanged. Targets remain .NET Framework 4.7.2 and .NET 10. Package, assembly and file versions are 2.1.3; applications that explicitly pin the assembly version should rebuild against this release.

Seven added synthetic regressions cover event fetching, raw text preservation, serialization round-trip, named and numeric-string input, unknown-name fallback and existing numeric values. The isolated suite contains 338 cases per framework. These tests do not establish behavior on physical gateways.

Nexity Cognito authentication remains explicitly unsupported; this patch does not add it. Existing event retry and recovery behavior is unchanged.
