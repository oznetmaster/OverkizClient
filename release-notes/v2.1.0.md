# OverkizClient 2.1.0

This release adds optional event-listener recovery and typed device helpers. Existing public method signatures remain available; no migration is required from 2.0.0.

- Use `FetchEvents(autoRegister: true)` to register a missing listener and allow one recovery attempt after an explicit listener or session rejection. Parameterless `FetchEvents()` keeps its explicit-registration behavior. Timeouts and transport failures are not retried because fetching consumes events.
- Fix listener requests after token refresh, duplicate registration during refresh, stale listener IDs after failed replacement and cleanup, and overlapping event operations.
- Clear cached setup, devices, gateways and listener state when selecting a different Rexel gateway or establishing a new cloud session.
- Add named and ordered-fallback state getters, CLR dictionary/list accessors, and attributed supported-alias models with most-featured-per-type selection.

The target frameworks remain .NET Framework 4.7.2 and .NET 10. Runtime dependencies are unchanged. The offline NUnit suite contains 323 cases per target.
